    How to Use This Form

    Press Job Spec Sheet — Sales Team Guide
    The Press Job Spec Sheet is a self-contained web page — no install, no server, no internet connection required. This guide covers filling it out, saving/loading drafts as files, exporting a job for prepress, and — for whoever maintains the form — how to safely add or remove button options.
    1. Filling Out the Form 2. Saving & Loading Drafts 3. Exporting a Job 4. Adding / Removing Options 5. Troubleshooting
    📋

    1. Filling Out the Form

    The form is split into sections — Job Info, Proof & Sign-Off, Job Callouts, Artwork, Tooling & Die, Stock & Substrate, Press Specs, Finishing & Packaging, Overs/Unders/Shipping, and Special Instructions, plus three optional add-on sections: RFID Inlay, Silk Screen, and Magnetic Encoding.

    The left sidebar lists them in two columns. The Required column is just a jump list — click a name to scroll straight to that section; those sections always stay in the form. The Optional column is where RFID Inlay, Silk Screen, and Magnetic Encoding live — click one to turn it on (green glowing halo) or off (plain grey). Off sections disappear from the form itself and are left out of anything you export, copy, or print.

    Button-group fields — click a button to select it (e.g. Proof Options, Press Target, Bleeds); click it again to clear it. These replace what used to be dropdown lists.

    Yes buttons — click to mark a callout Yes (PLI on Back, Arrow, Overage OK, etc.). Leaving it un-clicked means No — there's no separate No button to click.

    Conditional fields — a few sections reveal extra fields automatically:

    • Setting Proof Options to Customer Specific reveals a details field to describe it.
    • RFID Inlay Type is two steps: pick a chip family (Ultralight, Mifare Classic, Mifare Plus) and a row of that family's specific chip types appears below it.
    • Setting Silk Screen to Yes reveals Silk Screen Target, Screen Type, and a details box for the screen effect.
    • Setting Hole Punch to Yes reveals a details field for location/size/quantity.

    Only Proof Options is marked required (red asterisk); everything else is optional so you can send a partial spec sheet if that's all the customer has given you so far.

    💾

    2. Saving & Loading Drafts

    1
    Save Draft — 💾 Save Draft — opens your computer's normal Save window. Name the file whatever you like and save it to any folder, drive, or network location. It saves as a small .json file that includes every field and which sections are on/off.
    2
    Load Draft — 📂 Load Draft — opens your computer's normal Open window so you can pick any draft file you (or a teammate) saved earlier, from anywhere.
    ✅
    Drafts are portable files. Email one to a coworker, drop it on a shared drive, or carry it on a USB stick — opening it on any copy of this form brings that job right back.
    ⚠️
    The native Save window needs Chrome or Edge. Those browsers show a true Windows Save As dialog. Other browsers will still save the draft, just via a normal file download instead of a picker (check your browser's download settings if you want it to ask where to save every time).
    ⚠️
    Adding button options never breaks an old draft — a previous selection is still in the list. But if a button option gets renamed or removed later, loading an older draft will clear just that one field and show a yellow warning banner naming it — see section 4.
    📦

    3. Exporting a Job

    Three ways to get a finished spec sheet out of the form and to prepress/the press floor. All three skip any section you've turned off, lay section data out in two columns, and put Special Instructions in a single column at the very end:

    • 📋 Copy to Clipboard — copies a clean, two-column text summary. Paste it straight into an email, Teams/Slack message, or your job ticketing system.
    • ⬇️ Export Text — downloads that same summary as a .txt file named after the customer.
    • 🖨️ Print / PDF — opens your computer's Print window with a clean, button-free layout. Choose "Save as PDF" as the printer, and the very next window it opens is the same native Save window described in section 2 — name the PDF and pick a folder.

    Blank text fields show as —; blank Yes callouts show as No, since that's what leaving them unclicked means.

    🛠️

    4. Adding / Removing Button Options

    This section is for whoever maintains the form file, not day-to-day form users. Almost every button row's choices live in one place: a block near the top of the <script> called DROPDOWN_OPTIONS. RFID Inlay Type has its own two-step structure right below it, called RFID_FAMILIES. You don't need to touch any HTML to change either one.

    // Every key below becomes a row of buttons
var DROPDOWN_OPTIONS = {
  proofOptions: ["Standard", "Blind", "Customer Specific"],
  // ...
};

// RFID is a two-step picker: family button, then a row of that family's types
var RFID_FAMILIES = {
  "Ultralight":     ["UL 48", "UL 128", "UL C", "UL AES"],
  "Mifare Classic": ["Mifare Classic 1K", "Mifare Classic 4K"],
  "Mifare Plus":    ["Mifare Plus 1K"]
};
    1
    To add a choice to an existing button row: open the file in any text editor, find that field's array, and add a new "Choice Name" inside the square brackets, separated by a comma. Save the file and reload the page in the browser — that's it.
    2
    To add a whole new button-group field, add a new key: [...] line to DROPDOWN_OPTIONS, then in the HTML add <div class="btn-group" data-field="yourField" data-label="Your Label" data-options="yourKey"></div> — the page fills in the buttons automatically on load.
    3
    To add an RFID chip type, add it inside the right family's array in RFID_FAMILIES. To add a whole new family, add a new "Family Name": [...] entry — its button appears automatically alongside Ultralight and Mifare Classic.
    ✅
    Adding options is always safe. It never affects anyone's saved draft — old selections keep working exactly as before.
    ⚠️
    Renaming or deleting an existing option is not silent. Anyone with a draft that used the old text will see that one field cleared and flagged with a warning banner next time they load it (see section 2). This is by design — better a visible warning than a job silently shipping with the wrong spec.
    💬

    5. Troubleshooting

    I loaded a draft and one of my button selections disappeared.
    That option was renamed or removed from the form since you saved. Look for the yellow warning banner at the top of the page — it names the exact field so you can re-select the closest current option.

    Load Draft didn't do anything, or shows an error.
    Make sure you're picking the .json draft file you saved earlier, not some other file. A confirmation toast appears in the top-right once it loads successfully.

    Save Draft just downloaded a file instead of asking where to save.
    That means the browser you're using doesn't support the native Save window (see section 2) — try Chrome or Edge for the full experience, or check your browser's download settings.

    Copy to Clipboard didn't seem to do anything.
    Some browsers block clipboard access until you interact with the page first — click anywhere on the form once, then try the button again. A confirmation toast appears in the top-right when it works.

    Can multiple people use this at once?
    Yes — each person opens their own copy of the HTML file. There's no shared server or database, so hand off a job by sending someone the draft file (see section 2) or a finished Export/Copy summary.
