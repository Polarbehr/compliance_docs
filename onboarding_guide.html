How to Use This Form

Press Job Spec Sheet — Sales Team Guide
← Back to the Form
The Press Job Spec Sheet is a self-contained web page — no install, no server, no internet connection required. Open job_notes_spec_sheet.html in any browser on any PC and it works. This guide covers filling it out, saving/loading drafts, exporting a job for prepress, and — for whoever maintains the form — how to safely add or remove dropdown options.
1. Filling Out the Form 2. Saving & Loading Drafts 3. Exporting a Job 4. Adding / Removing Options 5. Troubleshooting
📋

1. Filling Out the Form

The form is split into sections — Job Info, Proof & Sign-Off, Job Callouts, Artwork, Tooling & Die, RFID Inlay, Stock & Substrate, Press Specs, Silk Screen, Finishing & Packaging, Overs/Unders/Shipping, and Special Instructions. Use the left sidebar to jump straight to any section — each link shows that section's icon plus a status dot that turns green once you've entered something in it.

Dropdowns — click and pick one option. Used wherever the spreadsheet had a fixed list of choices (e.g. Proof Options, Press Finish, Bleeds).

Yes / No toggles — click either pill to select it; click it again to clear it. Used for the simple callout fields (PLI on Back, Arrow, Overage OK, etc.).

Conditional fields — a couple of sections reveal extra fields automatically:

  • Setting Silk Screen to Yes reveals Silk Screen Target, Screen Type, and a details box for the screen effect.
  • Setting Hole Punch to Yes reveals a details field for location/size/quantity.

The Form Completion bar in the top-right fills in as you go — it's just a visual guide, not a hard requirement. Only Proof Options is marked required (red asterisk); everything else is optional so you can send a partial spec sheet if that's all the customer has given you so far.

💾

2. Saving & Loading Drafts

1
Save Draft stores everything currently in the form in this browser's local storage — 💾 Save Draft in the bottom action bar.
2
Load Draft — 📂 Load Draft — brings that saved data back into the form. Useful if you need to close the tab and pick a job back up later, or step away mid-call with a customer.
⚠️
A saved draft lives only in one browser, on one computer. It is not a file, it is not synced to a server, and it is not shared between machines. If you clear your browser's site data, switch computers, or open the form in a different browser, the draft won't be there. There is only one saved draft slot at a time — saving again overwrites the previous one. For anything you need to keep long-term or hand off to someone else, use Export Text (see next section) instead.
✅
New dropdown options never break an old draft. If the form gets new choices added to an existing dropdown after you saved a draft, loading that draft still works perfectly — your previous selection is still in the list.
⚠️
Renamed or removed options can. If a dropdown option you had selected gets renamed or deleted from the form later, loading an old draft will clear just that one field and show a yellow warning banner at the top of the page telling you exactly which field to re-check. Nothing else in the draft is affected — see section 4 for why this happens.
📦

3. Exporting a Job

Three ways to get a finished spec sheet out of the form and to prepress/the press floor:

  • 📋 Copy to Clipboard — copies a clean, labeled text summary of every field, grouped by section. Paste it straight into an email, Teams/Slack message, or your job ticketing system.
  • ⬇️ Export Text — downloads that same summary as a .txt file named after the customer, for attaching to a job folder or email.
  • 🖨️ Print / PDF — opens the browser's print dialog with a clean, button-free layout. Choose "Save as PDF" as the printer to get a PDF instead of a paper printout.

Blank fields show as — in the exported summary so it's obvious at a glance what still needs to be filled in.

🛠️

4. Adding / Removing Dropdown Options

This section is for whoever maintains the form file, not day-to-day form users. Every dropdown's choices live in one place: a block near the top of the <script> called DROPDOWN_OPTIONS, clearly marked with a comment header. You don't need to touch any HTML to change a dropdown's choices.

// Flat list — shows as a plain dropdown
var DROPDOWN_OPTIONS = {
  proofOptions: ["Standard", "Blind", "Customer Specific"],
  // ...

  // Grouped list — shows as labeled sections inside the dropdown
  rfidInlayType: {
    "UL Family":     ["UL 48", "UL 128", "UL C", "UL AES"],
    "Mifare Family": ["Mifare Classic 1K", "Mifare Classic 4K", "Mifare Plus 1K"]
  }
};
1
To add a choice to an existing dropdown: open the file in any text editor, find that field's array, and add a new "Choice Name" inside the square brackets, separated by a comma. Save the file and reload the page in the browser — that's it.
2
To add a whole new dropdown field, add a new key: [...] line to DROPDOWN_OPTIONS, then in the HTML add <select data-field="yourField" data-label="Your Label" data-options="yourKey"></select> — the page fills in the options automatically on load.
3
To group choices like the RFID Inlay Type dropdown, use an object of "Group Label": [...] instead of a flat array (see the second example above). Each group becomes its own labeled section in the dropdown.
✅
Adding options is always safe. It never affects anyone's saved draft — old selections keep working exactly as before.
⚠️
Renaming or deleting an existing option is not silent. Anyone with a draft that used the old text will see that one field cleared and flagged with a warning banner next time they load their draft (see section 2). This is by design — better a visible warning than a job silently shipping with the wrong spec. If you just need to fix a typo in an option's wording, expect a few of these warnings to show up for anyone with an in-progress draft; that's normal.
💬

5. Troubleshooting

I loaded a draft and one of my dropdown answers disappeared.
That option was renamed or removed from the form since you saved. Look for the yellow warning banner at the top of the page — it names the exact field so you can re-select the closest current option.

Load Draft says "No saved draft found."
Either you haven't clicked Save Draft yet on this computer/browser, or your browser's site data was cleared since the last save. Drafts don't transfer between computers or browsers — see section 2.

Copy to Clipboard didn't seem to do anything.
Some browsers block clipboard access until you interact with the page first — click anywhere on the form once, then try the button again. A confirmation toast appears in the top-right when it works.

Can multiple people use this at once?
Yes — each person opens their own copy of the HTML file in their own browser. There's no shared server or database, so two people's drafts never collide, but they also can't see each other's in-progress work. Use Export/Copy to hand a finished sheet to someone else.
